# VN-MURL SafeWeb — Architectural & Implementation Decisions

## Decision 1: Model Loading & Deserialization
- **Choice**: Direct unpickling of composite artifact `VN_MURL_SafeWeb_Final_Model.joblib` with `scikit-learn==1.6.1`.
- **Rationale**: The composite artifact was created during training with scikit-learn 1.6.1 and contains both branches (`security` with RandomForestClassifier and `child_safety` with Pipeline: StandardScaler + LogisticRegression) along with the metadata, exact feature columns list, and optimal decision thresholds. Matching the exact scikit-learn version eliminates `InconsistentVersionWarning` overhead and guarantees 100% numerical fidelity.

## Decision 2: Decision Thresholds & Hierarchy
- **Choice**:
  - Security (Phishing) Threshold: `0.425`
  - Child-Safety (Adult) Threshold: `0.140`
  - Priority: `PHISHING > ADULT > BENIGN`
- **Rationale**: Read directly from the trained artifact's metadata and validated against the validation F1 maximization search. If an URL tests positive for both threats, Phishing takes precedent as a critical security threat, while still reporting the secondary risk if requested.

## Decision 3: Zero Outbound HTTP Traffic During Prediction
- **Choice**: Strictly Lexical 48-feature extraction on the URL string alone.
- **Rationale**: Prevents Server-Side Request Forgery (SSRF), prevents child users from accidentally pulling obscene or illicit content through an internal crawler, ensures sub-millisecond classification latency, and functions reliably in air-gapped or network-restricted environments.

## Decision 4: Public Suffix Parsing via Offline tldextract
- **Choice**: Initialize `tldextract.TLDExtract(suffix_list_urls=None)` using bundled PSL snapshot.
- **Rationale**: Handles multi-segment ccTLDs correctly (e.g., `.com.vn`, `.edu.vn`, `.gov.vn`, `.org.vn`) without attempting outbound HTTP calls to fetch live Mozilla PSL updates during runtime.

## Decision 5: Database Strategy for ASP.NET Core
- **Choice**: Multi-provider support in Entity Framework Core. By default, connect to SQL Server (via connection string); fallback seamlessly to SQLite when running locally without a live SQL Server instance.
- **Rationale**: Ensures out-of-the-box local developer experience while matching the Dockerized SQL Server production deployment specified in requirements.

## Decision 6: Authentic Research Metrics Serving
- **Choice**: All research dashboard metrics, confusion matrices, ROC/PR curves, and feature importances are loaded directly from the authentic experiment output CSV and PNG files generated by the original Jupyter notebook run (`VN_MURL_outputs_FINAL`).
- **Rationale**: Zero fake or hardcoded metrics. The system serves authentic, empirical academic research outputs.
